# ЛАБОРАТОРНА РОБОТА № 5

**Тема.** Проєктування та програмна реалізація смарт-контракту кредитного протоколу з функцією емісії алгоритмічного стейблкоїна.

**Мета.** Вивчити фінансові принципи децентралізованого кредитування (DeFi Lending), засвоїти концепцію надмірного забезпечення (Over-collateralization) та розробити програмний комплекс для випуску синтетичного активу (стейблкоїна), прив'язаного до фіатної валюти.

**Виконав:** Вертій Максим

---

## Що я зробив

Я написав два смарт-контракти на Solidity та скрипти для їх розгортання й перевірки в локальній мережі Hardhat.

- **`StableCoin.sol`** — ERC20-токен **VertiiUSD**. Випускати та спалювати токени може лише власник, яким після розгортання стає `StableEngine`.
- **`StableEngine.sol`** — кредитний протокол. Користувач вносить ETH як заставу й випускає під неї стейблкоїни. Забезпечення 200%: борг не може перевищувати 50% вартості застави (ціна ETH = 2000 USD).

Функції `StableEngine`:

| Функція | Призначення |
|---|---|
| `depositCollateral()` | внести ETH як заставу |
| `mintStablecoin(amount)` | випустити стейблкоїни (з перевіркою Health Factor) |
| `burnStablecoin(amount)` | повернути стейблкоїни контракту; вони спалюються, борг зменшується |
| `withdrawCollateral(amount)` | зняти частину ETH; викликає `_revertIfHealthFactorIsBroken` |
| `healthFactor(user)` | поточний Health Factor користувача |
| `getMaxMintable(user)` | скільки ще можна випустити до ліміту |

## Скрипт моделювання (`scripts/simulateLending.js`)

Сценарій:

1. Користувач вносить 2 ETH (при ціні 2000 USD).
2. Скрипт програмно (бінарний пошук через `staticCall`) підбирає максимальну суму стейблкоїнів і випускає її — 2000 VertiiUSD, Health Factor = 1.0.
3. Користувач намагається зняти 1 ETH. Транзакція відкочується з помилкою `StableEngine__BreaksHealthFactor`; скрипт перехоплює її та виводить повідомлення, що захист спрацював успішно. Застава лишається незмінною.
4. Додатково: після спалювання половини боргу зняття 1 ETH проходить успішно.

## Структура проєкту

```
contracts/
  StableCoin.sol
  StableEngine.sol
scripts/
  deployLocal.js        # розгортання контрактів
  simulateLending.js    # сценарій з завдання
  lib/deploy.js         # спільна логіка розгортання, ім'я токена
```

## Запуск

```bash
npm install
npx hardhat compile
npx hardhat run scripts/deployLocal.js
npx hardhat run scripts/simulateLending.js
```

Потрібен Node.js 22.10 або новіший.

## Результат

У консолі видно, що користувач вніс 2 ETH, випустив 2000 VertiiUSD, а спроба зняти 1 ETH була відхилена: **захист спрацював успішно**.
